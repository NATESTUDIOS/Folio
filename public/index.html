What works offline?

  • Editor — fully offline
  • Files — saved to IndexedDB
  • Commit — queued, syncs on reconnect
  • Deploy — requires internet

Deploying

  • Click Host to deploy
  • Progress card shows percentage and stage
  • Copy live URL + short link from the result bar
  • Leave the tab open until deploy completes

Short link

  • Claim from the project page → Settings → Short link
  • Or click the link icon in the header to jump there
  • Copy it anywhere with the link button

Editor shortcuts

  • Ctrl+S — save
  • Ctrl+F — find
  • Ctrl+B — toggle sidebar
  • Tab — insert 2 spaces
  • Esc — close overlays
